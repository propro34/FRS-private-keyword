# FRS Private Keyword v2.1 — Strict Private Filter

نسخة مطوّرة بواجهة حمراء/سوداء متجاوبة، واستخراج اقتراحات متعدد المحركات، وجدول حي، وتحقق من ظهور الكلمات في صفحات الويب، وPrivate Filter قابل للإيقاف، وتصدير TXT.

## المزايا
- محركات اختيارية: Google، Bing، Yahoo، YouTube، Yahoo Japan. لا يوجد تحديد تلقائي.
- استخراج متعمق مع إزالة التكرار، ويستمر حتى تنفد الاقتراحات الجديدة أو يصل حد حماية الطلبات.
- جدول حي مع رقم عرض ومصدر وحالة تحقق من الويب. الأرقام لا تدخل في النسخ أو TXT.
- فحص العبارة عبر نتائج Bing Web Search ومحاولة جلب عناوين وصفحات فعلية.
- Private Filter الصارم يشترط وجود نتائج ويب، وثلاث كلمات على الأقل، وكلمتين وصفيتين إضافيتين غير شائعتين خارج الكلمة الأساسية، ويستبعد عبارات عامة مثل app/download/login/premium.
- إيقاف الفلترة مع الاحتفاظ بالنتائج الحالية.
- حفظ كل الكلمات أو النتائج المرشحة إلى TXT.
- واجهة Responsive للموبايل والحاسوب، نافذة فلترة محسنة، وشروط أكثر صرامة لاستبعاد العبارات العامة، وحالة تقدم واضحة.

## تشغيل محلي
1. ثبّت Node.js 18 أو أحدث.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ `npm install`
4. نفّذ `npm start`
5. افتح `http://localhost:3000`

## نشر Render
- أنشئ Web Service من مستودع GitHub.
- Build Command: `npm install`
- Start Command: `npm start`
- Runtime: Node.
- ارفع محتويات المجلد إلى جذر المستودع، بما فيها `server.js`, `package.json`, `index.html`, `public/index.html`.

## ملاحظة دقيقة حول «البحث القليل»
التحقق من وجود صفحات يثبت أن العبارة موجودة على الويب، لكنه لا يثبت عدد من يبحثون عنها. هذا الإصدار لا يدّعي امتلاك حجم بحث شهري ولا يخترع أرقاماً. شروط Private Filter تقلل العبارات العامة فقط؛ لا تثبت أن الكلمة نادرة أو منخفضة المنافسة. لا توجد بيانات حجم بحث شهرية أو API تجاري في هذه النسخة. للحصول على أرقام بحث شهرية موثوقة يلزم مزود بيانات كلمات مفتاحية وواجهة API ومفتاح صالح.

## ملاحظات تشغيل
- محركات الاقتراحات العامة قد تغيّر واجهاتها أو تحدّ الطلبات، لذا قد يفشل مصدر مؤقتاً.
- فحص الويب يستخدم Bing HTML وقد يتعطل إذا حجب المصدر الطلبات أو غيّر بنية الصفحة؛ عندها تظهر الحالة «تعذّر الفحص» بدلاً من الادعاء أن الكلمة غير موجودة.
- يوجد حد لعدد الكلمات التي تُفحص في طلب واحد لحماية الخدمة، ويجزّئ التطبيق الفحص إلى دفعات.
