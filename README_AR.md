# FRS Private Keyword

## التشغيل محليًا
1. ثبّت Node.js 18 أو أحدث.
2. نفّذ `npm install`.
3. نفّذ `npm start`.
4. افتح `http://localhost:3000`.

## الميزات
- واجهة ويب حمراء وسوداء متجاوبة.
- اختيار Google وBing وYahoo وYouTube وYahoo Japan بشكل مستقل.
- جدول مباشر يضيف كل كلمة فور وصولها مع رقم عرض ومصدر.
- النسخ والتصدير يخرجان الكلمات فقط، دون أرقام الجدول.
- Private Filter استدلالي للعبارات الطويلة والأكثر تحديدًا.
- لا يوجد حد ثابت لعدد الكلمات، لكن توجد حدود أمان لعدد عمليات البحث لمنع استمرار الطلبات بلا نهاية، كما تخضع المصادر لحدودها الخاصة.

## ملاحظات
- محركات البحث قد تغيّر واجهات الاقتراحات أو تحدّ الطلبات؛ ليس مضمونًا أن تعمل جميع المصادر دائمًا.
- Private Filter تقديري وليس قياسًا موثوقًا لحجم البحث أو ندرة الكلمات.
- التطبيق لا يجلب صفحات بحث عشوائية ولا يحتاج إلى API key لهذه المصادر العامة، لكن التوافر يعتمد على المصدر وقت التشغيل.

- الحفاظ على نتائج الفلترة الجزئية عند الضغط على إيقاف، مع ترتيبها وتحديث العداد.
